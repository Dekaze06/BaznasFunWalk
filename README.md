# Baznas Fun Walk 2026

Website Landing Page & Pendaftaran Baznas Fun Walk 2026 - Badan Amil Zakat Nasional Kabupaten Bandung.

## Fitur Utama
- **Hero & Countdown Banner**: Informasi jadwal, lokasi, dan countdown event.
- **Formulir Pendaftaran Interaktif**: Multi-step registration form untuk perorangan maupun komunitas.
- **Rute & Race Pack Info**: Visualisasi rute dan rincian fasilitas peserta.
- **FAQ & Kontak**: Informasi lengkap seputar acara.
- **Desain Modern & Responsif**: Dibangun dengan Astro JS & Vanilla CSS yang ringan dan cepat.

## Menjalankan Proyek Lokal

```bash
# Install dependencies
npm install

# Jalankan server lokal
npm run dev
# atau
npm start

# Build untuk produksi
npm run build
```
